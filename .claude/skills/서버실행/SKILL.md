# 로컬 테스트 서버 띄우기

기획자가 지금 코드 상태의 화면을 자기 브라우저에서 눌러볼 수 있게 만든다.
**사용자는 개발자가 아니다.** 명령어를 나열하지 말고 알아서 끝낸 뒤, 열린 주소 한 줄만 알려줄 것.

## 순서

### 1. 배포 파일 새로 만들기

```bash
cd web && npm run build
```

`web/dist/index.html` 한 파일이 화면 전체다. 이걸 새로 만들어야 최근 수정이 반영된다.
빌드하면 GitHub Pages 게시 경로인 `docs/index.html`(+ `og.png`)도 같은 내용으로 함께 갱신된다.

- **빌드가 실패하면 원인을 따지기 전에 `cd web && npm install` 을 한 번 돌리고 다시 빌드한다.**
  `git pull` 로 새 의존성이 들어온 직후가 가장 흔한 경우다(예: `korean-lunar-calendar` 추가 때
  실제로 이 문제가 났다). `esbuild` 만의 문제가 아니므로 오류 문구를 가리지 말고 무조건 한 번 시도.
- 그래도 실패하면 **서버를 띄우지 말고** 멈춘 뒤, 오류를 쉬운 말로 설명한다.
  (옛날 화면이 그대로 떠서 "반영됐다"고 착각하는 게 제일 나쁘다.)

### 2. 서버 켜기

```bash
python3 tools/serve-bg.py
```

이 한 줄이 **이미 떠 있는 우리 서버 정리 → 새로 실행 → 응답 확인(최대 10초)** 까지 다 한다.
성공하면 `✅ 서버 실행 중 (pid …) → http://localhost:8017` 를 찍는다.

- 포트는 **8017** 고정.
- **다른 프로그램이 8017을 쓰고 있으면 스크립트가 죽이지 않고 멈춘다**(종료코드 1).
  그 내용을 그대로 사용자에게 전달할 것. 남의 프로세스를 임의로 끄지 말 것.
- 실패하면 `/tmp/bujeokjip-server.log` 끝부분을 같이 보여준다.
- 끄고 싶으면 `python3 tools/serve-bg.py --stop`.

> `nohup … &` 로 띄우지 말 것. 부모는 끊겨도 프로세스 그룹이 호출한 셸에 남아,
> Claude Code가 셸을 정리할 때 서버까지 같이 죽는다(실제로 두 번 그렇게 내려갔다).
> `serve-bg.py` 는 `os.setsid()` 로 자기 세션을 갖게 해서 이 문제를 없앤다.

### 3. 계산이 되는지 확인 (건너뛰지 말 것)

서버만 떠 있고 화면이 깨져 있으면 아무 소용이 없다. **주소를 알려주기 전에** 회귀 케이스로 확인한다.

- 입력: **1979년 2월 2일 16시 45분 · 서울**
- 기대: 사주팔자 `무오 을축 경자 갑신` · 용신 한자 `火`
- 콘솔 에러 0

확인 방법은 상황에 맞게(브라우저 도구로 폼을 채워 `#btnFind` 클릭 후 `#pillars`·`#yongGlyph` 읽기 등).
**기대와 다르거나 오류가 나면 주소를 알려주지 말고 먼저 그 사실을 보고한다.**

### 4. 기본 브라우저로 열기

```bash
open http://localhost:8017
```

`/` 로 들어가면 `web/dist/` 가 뜬다(서버가 알아서 연결해 둠).

### 5. 보고

이렇게만 알려준다.

- 열린 주소: **http://localhost:8017**
- 방금 빌드해서 지금 코드 상태가 반영돼 있다는 것
- 3단계 확인이 통과했다는 것(한 줄)
- 화면을 고친 뒤 다시 보려면 이 명령(`서버실행`)을 한 번 더 돌리면 된다는 것
- 서버는 계속 떠 있으니 브라우저만 새로고침해도 되지만, **코드를 고쳤으면 새로고침만으로는 안 바뀐다**(빌드가 필요하므로 이 명령을 다시 실행)

## 알아둘 것

- 브라우저에서 화면이 안 바뀌면 십중팔구 **빌드를 안 한 것**이다. 이 명령은 항상 빌드부터 한다.
- 그래도 옛날 화면이면 브라우저 강력 새로고침(맥: `Cmd + Shift + R`)을 안내한다.
- 페이지가 아예 안 열리면 서버가 내려간 것일 수 있다. 따질 것 없이 이 명령을 다시 돌리면 된다.
- 문구를 바꾸러 온 거라면 이 명령이 아니라 `메타반영` 이다. `메타반영` 은 문구 반영 + 빌드까지 하므로,
  그 뒤에 화면을 보고 싶을 때 이 명령을 이어서 쓰면 된다.
- 인터넷이 끊겨 있어도 동작한다(폰트만 시스템 글꼴로 대체됨). 계산은 전부 브라우저 안에서 한다.
